# SOFTWARE SISTEMA DE SÓCIO TORCEDOR DE UM CLUBE (1º SEMESTRE)💻
<h4>
    Software desenvolvido em Python para representar, de forma prática, um sistema de sócio torcedor de um clube de futebol, permitindo o controle de usuários e a aquisição de ingressos com base nos benefícios disponíveis para cada modalidade.⚽
</h4>

# LINGUAGEM USADA🐍
- Python 3.11

<h4>📚Bibliotecas usadas:</h4>
• random

# COMO TESTAR❓
1. Instale o Python em seu desktop: [Instalar Python](https://www.python.org/downloads/)🐍
2. Baixe o arquivo PIM_SocioTorcedor.py💾
3. No Windows Explorer, duplo clique sobre o arquivo baixando anteriormente.🗂️
4. O arquivo irá executar em um terminal/CMD do Windows.🪟
